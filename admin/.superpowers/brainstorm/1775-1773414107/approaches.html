Admin panel overhaul — 3 approaches

Pick the scope that feels right. We can always expand later.

A

Fix the pain points Focused · Lower risk

Target only the known problems. Everything else stays as-is.

  • Add a dashboard home page with connector health + failed job counts
  • Regroup sidebar into Connectors / Discord / Shop
  • Convert connector detail page to tabbed layout (Overview, Routes, Jobs, Settings)
  • Surface job failure counts on the connectors list

Pros

  • Fastest to ship
  • Low regression risk

Cons

  • Other pages still clunky
  • Misses opportunity for cohesive improvement
B

Full overhaul Recommended ✦

Redesign the entire admin panel coherently — navigation, layout, and individual pages — while keeping the existing dark theme and tech stack.

  • Dashboard home — connector health, job stats, quick links
  • Sidebar — Connectors / Discord / Shop groups + contextual sub-nav when inside a connector
  • Connectors list — richer table with inline health indicators (failed jobs, last seen status)
  • Connector detail — tabbed: Overview, Routes, Jobs, Settings
  • Filtering page — improved layout, clearer route selection UX
  • Shop pages — consistent card-based layout, better visual hierarchy
  • Customers page — improved search + action panel layout

Pros

  • Cohesive, polished result
  • Fixes all known pain points
  • Better foundation for future features

Cons

  • More work
  • More files touched
C

Full overhaul + visual rebrand Most ambitious

Everything in B, plus a refreshed visual design — new colour accents, updated typography scale, improved component styling beyond what shadcn ships with.

  • All of Approach B
  • Refreshed colour system (keep dark base, update accent palette)
  • Improved card and table styling
  • Better status indicators (colour-coded badges, health dots)
  • Polished empty states and loading states

Pros

  • Most polished end result
  • Feels like a proper product

Cons

  • Highest effort
  • CSS changes can have broad impact
